# Minecraft Java Seed Atlas

Minecraft Java Edition **26.3 · 26.2 · 26.1 · 1.21 계열**의 독특한 바이옴·지형 시드를 찾아보세요. 버전마다 100개씩, 총 **400개**의 시드를 검색하고 복사할 수 있습니다.

## 이용 방법

1. 원하는 **버전·지형·출처 확인 방식**을 선택하세요.
2. 설명, 시드 숫자, 원문 버전, 출처 이름이나 좌표로 **검색**하세요.
3. 카드의 출처와 좌표를 살펴보고 **시드 블록을 눌러 복사**하세요. 무작위 버튼으로 현재 조건에 맞는 시드를 골라도 좋습니다.

## 월드를 만들기 전에

**Java Edition의 카드에 표시된 원문 버전**을 확인하세요. 1.21 계열은 여러 1.21.x 버전의 자료를 묶은 것으로, 다른 버전이나 Bedrock Edition에서 같은 지형을 보장하지 않습니다. 기본 월드 유형과 구조물 생성 활성화를 기준으로 하며, 좌표는 원문의 관심 지점입니다.

확인 방식은 **출처의 게임 확인 기록 · 원문 버전 명시 · 지도 계산 자료**로 구분합니다. 출처의 기록을 대조한 목록이며, 이 프로젝트에서 모든 시드를 직접 게임으로 재검증한 것은 아닙니다. 자세한 근거는 카드와 [전체 시드·출처 목록](data/minecraft_java_unique_biome_terrain_seeds.md)을 확인하세요.
